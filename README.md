# 精神科病棟 身体急変サポート

精神科単科病棟（高齢者・認知症が多い病棟）で身体急変が起きたときに、**院内で治療を続けるか、搬送・転院するか**の判断を補助するアプリです。iPhoneのホーム画面に追加して、圏外でも使えます。

## できること

| 段階 | 内容 |
|---|---|
| 背景 | 入院形態、既往、ハイリスクの薬（クロザピン・リチウム・抗凝固薬など）、普段の状態、本人・家族の意向（ACP） |
| バイタル | NEWS2・qSOFAを自動計算、推移の表 |
| 症候（19種） | 確認事項、レッドフラッグ、搬送相談、夜間の判断、院内継続の条件、服薬に関連した注意 |
| 検査 | 日中・夜間にできる検査の表示（施設の設定で変更）、検査値の注意 |
| 鑑別・初期対応 | 高齢者・認知症・向精神薬を踏まえた鑑別と院内での初期対応 |
| 判断 | 「すぐ搬送／搬送を相談／院内で継続」の目安と理由、意向に応じた注意 |
| 文書 | SBAR報告、紹介状（診療情報提供書）、情報提供（箇条書き）、カルテ記録（SOAP） |

## ファイル

- `index.html`・`app.js`：アプリ本体
- `data.js`：症候別の内容（ここを直すと内容が変わる）
- `excel/身体急変サポート.xlsx`：Excel版（`node tools/export.js` → `python3 tools/build.py` で再生成）

## 注意

- 判断の補助のための目安です。最終判断は診察した医師が、施設の手順・地域の救急体制・本人と家族の意向を踏まえて行ってください。
- NEWS2は英国王立内科医協会（RCP）の基準に基づきます。症候別の内容は一般的な知見の要約で、ガイドラインや施設の手順に代わるものではありません。
- 入力内容は端末内にのみ保存されます。このリポジトリに患者情報を置かないでください。
